# docs — 设计与计划

这个目录放重构本仓库时的设计文档，**对学习者来说不是必读**。如果你只想跟着 tutorial 走，可以跳过整个 docs/。

## 现在有什么

- `superpowers/specs/` — 重构 spec：为什么从官方文档式教程改成"双轨 + 任务卡"
- `superpowers/plans/` — 实施 plan：怎么一步步把仓库改成现在这样

## 未来会有什么（Phase 2-3 之后）

- `prompts-cheatsheet.md` — 高频 prompt 速查表（按场景查）
- `debug-recipes.md` — 报错 → 诊断 prompt 的对照表
- `concepts/` — 难点小词典（按需新增）

这些会随 week-2/3/4 tutorials 一起加。

## 为什么放这

按 [`superpowers`](https://github.com/anthropics/superpowers) 的约定，spec / plan 跟代码一起进 git，这样 fork 者也能看到"这个仓库是怎么演化过来的"。
